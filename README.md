# Lorraine

**An office suite for AmigaOS 3.x** — *Una suite ofimática para AmigaOS 3.x.*

- **Lorraine Calc:** spreadsheet / hoja de cálculo.
- **Lorraine Write:** word processor / procesador de textos.

Both open and save LibreOffice (ODF: `.ods`, `.odt`) and modern Microsoft Office (OOXML: `.xlsx`, `.docx`) files.
Native MUI interface. Written in [Dash](https://github.com/FreeMEM/dash), a language that compiles to C for the Amiga.

Los dos abren y guardan los ficheros de LibreOffice y de Microsoft Office moderno. Interfaz MUI nativa. Escrito en
Dash.

*Lorraine* was the code name of the Amiga prototype in 1984.
